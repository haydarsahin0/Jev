arXiv Radar

Henüz tarama verisi yok

data/index.json bulunamadı. Bu dosyayı tarama iş akışı üretir. Kurulumu tamamlamak için:

  1. Depo ayarlarında Settings → Secrets and variables → Actions bölümüne TYPESAFE_API_KEY secret'ını ekleyin.
  2. Settings → Pages → Source ayarını GitHub Actions olarak seçin.
  3. Actions → arXiv Radar → Run workflow ile limit = 3 vererek ilk taramayı ucuza çalıştırın.
  4. İş akışı bittiğinde bu sayfa kendiliğinden dolar. Sonrasında hafta içi her sabah 05:00 UTC'de otomatik çalışır.
